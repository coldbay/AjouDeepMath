제5회 대학 연합 아주 소중한 딥러닝 챌린지 2026 — 대회 규칙 (Rules) 📋

본 규칙에 참가 등록을 함으로써 동의한 것으로 간주됩니다. 규칙에 명시되지 않은 사항은 주최 측의 판단에 따릅니다.

1. 대회 기본 정보

항목 내용
대회명 제5회 대학 연합 아주 소중한 딥러닝 챌린지

문의 AI융합교육원 (031-219-3070)

2. 참가 자격 (Eligibility)

a. 참여 대학(경북대, 경희대, 부산대, 아주대, 전남대, 전북대) 소속 학부생에 한하여 참가할 수 있습니다.

b. 2026-1학기 기준 휴학생도 참여 가능합니다. 단, 상금 지급은 지급 시기(2026-2학기) 재학생만 가능합니다. (8월 졸업자, 학사취득유예, 휴학생 등은 상금 지급 불가)

c. 문제 공개 후 자체 스터디 또는 그룹 스터디 등의 참여를 통한 자기주도학습이 가능한 학부생을 대상으로 합니다.

d. 주최 기관(AI융합교육원)의 운영진은 대회에 참여할 수 없습니다.

4. 모델 규칙 (Model Rules)

4.1 베이스 모델

a. 모든 참가자는 Qwen/Qwen2.5-3B-Instruct를 유일한 출발점으로 사용해야 합니다.

b. 다른 모델(Qwen2.5-Math, DeepSeek-R1, Llama, GPT 등)을 베이스 모델로 사용하거나, 다른 모델의 가중치를 병합(merge)하는 것은 금지됩니다.

4.2 허용되는 학습 기법

아래 기법들은 자유롭게 사용할 수 있습니다.

  • Full Fine-Tuning, LoRA, QLoRA 등 파라미터 효율적 학습 (PEFT)
  • SFT (Supervised Fine-Tuning)
  • RL 기반 학습 (GRPO, DPO, PPO, KTO 등)
  • 데이터 증강 (Augmentation), 커리큘럼 학습 (Curriculum Learning)
  • 양자화 (Quantization)

4.3 금지되는 행위

  • 베이스 모델 외 다른 모델의 가중치를 로드하거나 병합하는 행위
  • 추론 시 외부 모델을 호출하여 앙상블하는 행위
  • 사전 학습(Pre-training)을 처음부터 수행하는 행위 (Fine-tuning만 허용)

5. 데이터 규칙 (Data Rules)

5.1 제공 데이터

a. 주최 측이 제공하는 학습 데이터를 기본으로 활용합니다.

b. test.parquet의 문제를 학습 데이터로 사용하는 것은 금지됩니다.

5.2 외부 데이터

a. 공개 데이터셋의 추가 사용은 자유입니다. 단, 해당 외부 데이터는 모든 참가자가 무료로 동등하게 접근 가능한 공개 데이터여야 합니다.

b. 유료 구독, 특수 라이선스, 또는 비공개 협약이 필요한 데이터의 사용은 금지됩니다.

c. 사용한 외부 데이터셋은 최종 제출 시 목록을 명시해야 합니다.

5.3 상용 API 사용

a. 학습 데이터 구축 목적의 상용 API 사용은 허용됩니다. (예: GPT-4를 사용한 풀이 생성, 데이터 증강 등)

b. 상용 API를 이용하여 test.parquet의 문제에 대한 답을 직접 생성하는 것은 금지됩니다.

c. 테스트 문제를 검색 엔진이나 외부 서비스에 입력하여 답을 찾는 행위는 금지됩니다.

6. 추론 규칙 (Inference Rules)

a. 추론 시 인터넷 접속이 차단됩니다. (외부 API 호출, 웹 검색 등 불가)

b. 모든 추론은 제공된 환경 내에서 로컬로 수행해야 합니다.

c. Majority Voting, Self-Consistency, Best-of-N 등 테스트 타임 기법은 자유롭게 사용할 수 있습니다.

7. 평가 (Evaluation)

7.1 리더보드

a. 실시간 리더보드 (Public Leaderboard)

  • 대회 기간 중 실시간으로 운영됩니다.
  • test.parquet의 일부 (Public Test, 30%)를 사용하여 채점합니다.
  • 이 점수는 최종 순위에 영향을 미치지 않습니다.

b. 최종 리더보드 (Private Leaderboard)

  • 대회 종료 후 최종 평가를 수행합니다.
  • test.parquet의 나머지 (Private Test, 70%)를 사용하여 채점합니다.
  • 최종 순위는 이 점수로 결정됩니다.

7.2 채점 방식

a. 모든 문제의 정답은 정수입니다.

b. 제출된 정수와 정답이 정확히 일치하면 정답, 그렇지 않으면 오답으로 판정합니다.

c. 평가 지표: Accuracy (Exact Match)

d. 모델 출력에서 최종 답을 추출하는 후처리(post-processing)는 참가자가 직접 수행합니다.

8. 제출 규칙 (Submission Rules)

8.1 제출 형식

a. 파일명: submission.csv

b. 파일 구조: ID와 answer 두 개의 컬럼

ID answer
prob_0001 42
prob_0002 7
prob_0003 125

c. answer 컬럼에는 정수만 기입해야 합니다.

d. 모든 문제에 대한 답이 포함되어야 하며, 빈 값은 오답 처리됩니다.

8.2 수상 후보자 의무

a. 수상 후보자는 다음을 제출해야 합니다:

  • 학습 코드 (training code) 및 추론 코드 (inference code)
  • 학습된 모델 가중치
  • 사용한 데이터셋 목록 및 접근 방법
  • 재현에 필요한 환경 설명 (하드웨어, 라이브러리 버전 등)
  • 방법론 설명 문서 (아키텍처, 전처리, 학습 세부사항, 하이퍼파라미터 등)

b. 주최 측은 수상 후보자에게 재현 검증을 요청할 수 있으며, 재현이 불가능한 경우 수상이 취소될 수 있습니다.

9. 팀 규칙 (Team Rules)

a. 개인 또는 팀으로 참가할 수 있습니다.

b. 한 사람이 여러 팀에 소속되는 것은 금지됩니다.

c. 같은 소속 대학이 아니더라도 참여 대학 6개교 소속 학부생이라면 팀 구성이 가능합니다.

10. 부정행위 및 제재 (Misconduct & Penalties)

10.1 부정행위로 간주되는 행위

a. 테스트 데이터의 정답을 외부에서 확보하여 제출하는 행위

b. 다른 참가자의 코드, 모델, 또는 제출물을 무단으로 사용하는 행위

c. 여러 계정을 사용하여 제출 횟수 제한을 우회하는 행위

d. 리더보드 점수를 이용하여 정답을 역추적(probing)하는 행위

e. 본 규칙을 우회하기 위한 의도적인 행위

10.2 제재

a. 부정행위가 확인된 경우, 해당 참가자(팀)는 실격 처리되며 수상 자격이 박탈됩니다.

b. 주최 측은 필요 시 추가적인 제재를 할 수 있습니다.

11.3 상금 지급

a. 상금은 2026-2학기 기준 재학생에게만 지급됩니다.
